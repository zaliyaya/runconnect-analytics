# Пульс RunConnect

Недельный отчёт по приложению RunConnect: рост, продукт, качество и выводы недели.

- Сайт: https://zaliyaya.github.io/runconnect-analytics/
- Данные: `weeks.json` — один объект на неделю (пн–вс по Москве), ключ `week` = дата понедельника.
- Обновление: по команде «обнови отчёт» Claude собирает новую неделю и коммитит обновлённый `weeks.json`. Страница `index.html` при этом не меняется.
